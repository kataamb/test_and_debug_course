# PPO Ambartsumova 



1. Название проекта

Приложение для площадки объявлений
  
2. Краткое описание идеи проекта (1 абзац, 3 предложения)


   Приложение, на котором размещены различные объявления. Пользователи могут просматривать объявления, добавлять их в избранное. Объявления создает пользователи, в объявлении указывает товар или услугу, которую может предложить. 
   
3. Краткое описание предметной области (1 абзац)

Предметная область приложения для площадки объявлений охватывает рынок товаров и услуг, предлагаемых пользователями. Платформы объявлений служат связующим звеном между продавцами и покупателями, позволяя пользователям легко находить нужные товары и услуги и взаимодействовать друг с другом для осуществления сделок.

5. Краткое обоснование целесообразности и актуальности проекта (1 абзац)

Проект приложения для площадки объявлений является актуальным в условиях растущего интереса к онлайн-торговле и обмену услугами. Предлагаемое решение включает в себя новые особенности - лаконичный интефрейс категорий и наличие фильтра по дате объявлений, что сделает приложение более удобным для пользователей.


6. Краткое описание акторов (ролей)
  
  - незарегистрированные пользователи ( могут просматривать и искать объявления )
  - зарегистрированные пользователи ( могут просматривать и искать объявления, добавлять объявления в избранное, создавать сделки, может создавать, удалять и редактировать свои объявления);
  - администратор - пользователь с правами суперпользователя, может делать то же, что и зарегистрированный пользователь, а также удалять чужие объявления;
